# case2

REST API на Express для учёта заявок на техобслуживание оборудования
производственной площадки (ветропарк).

## Требования

- Node.js >= 18 (используется нативный `fetch`)
- npm

## Установка и запуск

```bash
cp .env.example .env
npm install
npm run dev     # nodemon
npm start       # production
